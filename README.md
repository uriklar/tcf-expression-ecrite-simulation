# tcf-expression-ecrite-simulation

## Writing task source

The default Tâche 1, Tâche 2, Tâche 3 trainer banks and **Simulation complète** use all 46 combinations extracted from the saved Formation TCF Canada page **Sujets Expression Écrite Janvier 2026**.

- Generated source data: `src/data/january2026Tasks.json`
- Reproducible extractor: `scripts/extract-january-2026-tasks.py`
- Integrity check: `npm run verify:task-bank`

Tâche 3 preserves both complete source documents. Corrections/model answers from the saved page are deliberately excluded.
